# Changelog

## Unreleased

### Fixed

- Disable the split action if the active editor cannot be split.

## 1.0.1

### Changed

- Require IDE restart for the plugin to take effect.

## 1.0.0

### Added

- Actions to focus neighbouring splitter in any direction.
- Actions to split the editor in any direction, optionally moving the active tab into the new splitter.
- Actions to swap neighbouring splitters.
- Actions to rearrange tabs within a splitter.
- Actions to move tabs into a neighbouring splitter.
- Setting to configure the neighbour selection strategy.
- Setting to allow tabs to be moved in any direction by automatically splitting.
